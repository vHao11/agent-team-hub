# 交易接口变更分析

## 输入

- `change_document`：明确版本的接口变更材料。
- `code_workspace`：本机已经存在的代码工作区。
- `work_item_id`：已有共享事项编号；未提供时先完成分析，不自动新建事项。

## 工作方法

1. 阅读材料，记录发布主体、版本、发布日期和生效时间；材料不明时写明待确认。
2. 检索代码中的接口结构、枚举、序列化、错误码和处理链路，给出可定位的文件引用。
3. 分别检查申报、撤单、回报、断线重连、兼容解析以及清算交收影响。
4. 按“明确受影响、可能受影响、当前证据未发现影响”组织结果，不能把推测写成已验证结论。
5. 给出修改建议、联调样例、回归用例和需要其他组提供的材料。
6. 为关联事项追加摘要、阻塞点和下一步；仅在负责人明确要求时提交交付。

## 输出

按 `references/report-template.md` 写报告。每项结论包含材料出处或代码引用。台账交付使用接收方可读的附件或仓库引用，本机绝对路径不能视为已经共享。

## 完成边界

分析完成不代表代码已经修改；运行成功不代表跨组验收通过。提交交付后由指定验收人处理。
